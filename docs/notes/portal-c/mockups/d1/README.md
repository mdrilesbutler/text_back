# d1 — Spine
Idea: every page is one vertical story read top to bottom. A thin spine runs down the left with one node per thing that matters: setup items on Home, the conversation's steps on Messages, rules on Schedule, numbers, forwarding and the five checks on Phone, the connection on Calendar.
Two node kinds, never both on one fact: state nodes (2px #78716c ring) draw the status: filled tick = Done, empty ring = Needs you / Not yet, dashed tick = You checked this. The word sits beside them in a pill with no second glyph. Icon nodes (1px decorative ring) only label a section. A short tick on the line marks a sub-heading.
Borrowed from A: portal.css and its anatomy: message card (head, bubble, receipt line, Edit wording / Reset foot), amber cost warning, the one-input code entry, switch rows, pill radios, choice cards, the phone frame and thread.
New in round 1: a white page; real forms (every control named, one Save per form, Reset and fixes post); a Save bar that takes the bottom-nav slot only while something changed, saying what changed, on Messages, Schedule and Phone; toasts that name the change; plain textareas with [Business name]-style inserts; wording rules inside the editor; no tinted band or sender label around bubbles.
Honesty: the "Network notice" marker leads every TextBack bubble while approval is pending, with the hint line on the page and under the example; This week is tagged "Example numbers"; the example asks only switched-on questions (build.py asserts it).
Also: error summaries on every error state, inline confirm (no modal) for Sign out everywhere, Account in the desktop sidebar, a desktop rail that stays below the header and scrolls its own thread, and d1.js (27 lines, optional) that marks the jump chip for the step on screen.
Signature element: the spine with its red missed-call dot on the Messages "Missed call" node, the same mark that opens the example thread, so the settings page and the customer's phone read as the same story.
Chrome budget on a phone: header 56 + jump chips 44 (Messages only) + bottom nav or Save bar 56 = 156; html scroll-padding matches, cards add 12px of scroll-margin.
Strings the fixture lacks live in proposed-copy.json (merged over fixture.json by build.py); each is a proposal for the fixture and copy deck.
